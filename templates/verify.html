Drop a full evidence package (.zip) or a locations KMZ produced by this tool, or a KMZ exported by TAK Server itself. It is read entirely in your browser - nothing is uploaded. Only a SHA-256 hash of the file is sent to the server, to check it against the export audit log; no file content and no location data leaves your machine. A file this tool did not produce replays but cannot be verified, and the page says so.

Hash check looks this file's hash up in the audit log; a match shows the entry recorded at export time - who ran it, when, the window and area requested, and any channel filter. The Audit match line inside it goes one step further: it checks whether this file's actual data (its real first-to-last report times, below) falls inside the window that was recorded, since a requested window and the data it actually turned up are related but not always identical facts.

File contents is not looked up anywhere - it is computed directly from what's inside the file you dropped: how many people/entities and positions it holds, and their true time range.

What this package is

Checks the package's positions against a second reading of the database.

The Export page shows the administrator one command that re-runs the package's statements on the TAK Server itself and writes recheck-*.csv files and a hash file. Choose recheck-cot_router-raw.csv here: it is checked against the package's own cot_router-raw.csv exactly by row id - every id present on both sides with identical values - and its SHA-256 is shown and looked up. An administrator can record the file in the audit log beside the package. recheck-positions-plain.csv compares against cot.csv the same way.

Beneath the exact check, a per-device table matches by callsign, time and position (within 1 second and 1 metre) - the comparison used for KML/KMZ files, which carry no row ids. Files are read in your browser; only a SHA-256 hash is sent, and only when you record one.

Click a dot for full record details - only available when the loaded file is a KMZ (a package's cot.csv has no equivalent pre-built detail block).
