Optional: an administrator's re-check on the TAK Server
This is corroboration, over and above what is required: the package and its entry in the audit log stand on their own, and one without a re-check is not deficient. What it adds is a second program's word - the package was read from the TAK Server database by this tool, and the re-check is the same statements run again on the server by the administrator with psql, producing files this tool never touched. Best run now, while the server still holds the rows. The one line below fetches the package's queries.sql from this page's server (the same bytes as in the zip; its hash is in SHA256SUMS.txt), runs it in one read-only snapshot into a folder kept for the case, hashes every result, tars the folder, and posts only the list of hashes back here, where it is recorded in the audit log. No location data travels either way. One line in that list is expected to equal the cot_router-raw.csv line in the package's SHA256SUMS.txt: the raw rows are written by both this tool and psql in the same form. If they match, the file the server wrote and the one in the package have the same hash. The other re-check files match by content, not by hash. Do this now: the server deletes records after its retention period, and after that no re-run is possible. Self-signed certificate: if this page's address shows a certificate warning in the browser, tick the box so curl on the server accepts it too (-k).
